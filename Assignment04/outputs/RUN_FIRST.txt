Actual GloVe prediction results are generated by running the notebook or Python program in a network-enabled environment. The authoring workspace could not download the pretrained vectors, so no predictions or scores have been fabricated.

Run from this folder:
  pip install -r requirements.txt
  python 421135_Affan_Khan_Samid_Khan_NLP_Assignment04.py --output-dir outputs

The script downloads/caches glove-wiki-gigaword-50 (about 65 MB on first run) and writes predictions.csv, ranked_candidates.csv, skipped_oov_examples.csv, metrics.json, results.txt and cosine_scores.png.
