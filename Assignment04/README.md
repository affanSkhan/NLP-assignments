## Model
The code uses Gensim's pre-trained `glove-wiki-gigaword-50` vectors (GloVe, 50 dimensions, about 400,000 vocabulary words). It downloads the model on first run and caches it thereafter.

## Run
From this directory, with Python 3.10+ and internet access for the initial model download:

    pip install -r requirements.txt
    python 421135_Affan_Khan_Samid_Khan_NLP_Assignment04.py

A one-off example:

    python 421135_Affan_Khan_Samid_Khan_NLP_Assignment04.py --capital-1 Athens --country-1 Greece --capital-2 Baghdad

The program computes v(country_1) - v(capital_1) + v(capital_2), ranks a curated country vocabulary by cosine similarity, removes input terms, and writes predictions, top-five ranked candidates, JSON metrics, results text and a cosine-score chart to `outputs/`.

**Reproducibility note:** model weights could not be downloaded by the workspace that prepared the files, so actual score outputs are generated by running the attached script in a network-enabled environment. No model predictions or accuracy values are fabricated. The documented reference examples in `outputs/reference_sanity_examples.csv` are clearly separated from the 20-case evaluation.
